# ADR-002: Estructura inicial del projecte

## Status
Acceptat

## Context
Com que és el meu primer projecte d'aquest tipus (full stack amb React al
frontend i Node/Express al backend), i a la primera classe es va decidir de
fer 2 monorepos (frontend & backend)
No tinc gaire experiència prèvia gestionant projectes amb frontend i
backend independents, així que he optat per la opció que em sembla més
clara d'entendre i mantenir de moment

## Decisió
Faré servir dos repositoris separats a GitHub: `frontend_kakapos` i
`backend_kakapos`, cadascun amb el seu propi historial de commits

## Conseqüències
+ Cada repositori té les seves pròpies dependències (package.json,
  node_modules), així que no barrejaré
+ Puc fer commits i pujar canvis d'un costat sense afectar l'altre, cosa
  que m'ajuda a no perdre'm mentre encara vaig aprenent Git
- No oblidar-me d'actualitzar un repositori quan canvio alguna cosa que
  afecta els dos (ex: una API)
- Per clonar o configurar el projecte sencer calen dos `git clone` en
  comptes d'un, cosa que pot ser una mica més pesat si en algun cas
  (que no serà així en aquest projecte) s'hagues d'unir un altre participant
